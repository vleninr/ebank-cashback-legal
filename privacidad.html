Política de privacidad de ebank Cashback (POC)

Esta aplicación usa la API de Gmail únicamente con el permiso gmail.send, para enviar correos de notificación (confirmación de inscripción, aprobaciones, fallos del proceso y abonos) desde la cuenta ebank1908@gmail.com

La aplicación no lee, no almacena ni comparte el contenido de ningún buzón de Gmail, y no usa los datos de Google para publicidad ni para entrenar modelos.

Los datos de los destinatarios los entrega el propio módulo y se usan solo para enviar el correo.

Para consultas o para pedir la eliminación de datos, escribe a ebank1908@gmail.com

Última actualización: 1 de noviembre de 2026.
